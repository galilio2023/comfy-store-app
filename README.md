# Comfy Store

## Overview
Comfy Store is a modern e-commerce application designed to provide a seamless shopping experience. Built with React and Vite, it leverages the latest technologies for optimal performance and user engagement.

## Tech Stack
- **React**: A JavaScript library for building user interfaces.
- **Vite**: A fast build tool and development server.
- **Redux Toolkit**: For state management.
- **React Query**: For data fetching and synchronization.
- **Axios**: For making HTTP requests.
- **Day.js**: For date manipulation.
- **Tailwind CSS**: For utility-first styling.
- **DaisyUI**: For pre-designed components.

## Installation
To get started with Comfy Store, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/galilio2023/comfy-store-app.git
   ```
2. Navigate into the project directory:
   ```bash
   cd comfy-store-app
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

Now you can access the application at `http://localhost:3000`.
